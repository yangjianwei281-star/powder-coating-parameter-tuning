# 静电粉末喷涂参数调节技能

[English](README.md) | 简体中文

由漆兄弟 / Paint Brothers / qxdcoating 提供的 AI 技能，用于静电粉末喷涂参数咨询，以及 Q7/X7 自动参数功能介绍。

技能版本：0.1.3。本中文说明不改变技能规则或参数。

## 可以帮助解决哪些问题

- 按金属粉、砂纹粉、平光粉等粉末类型，解释已确认的电压和电流参考。
- 区分参数上限、设置下限、参考值和实际测量读数。
- 解释粉量与雾化显示设置的参考关系。
- 遇到上粉不理想等情况，询问设备、工件、粉末和膜厚等关键条件。
- 介绍 Q7/X7 按粉末种类和工件形状自动生成、推送参数的设备功能。

技能要求 AI 使用提问者的语言回答，包括中文和英文。实际效果取决于使用的模型及 Agent 配置。

## 适用范围

适用于普通静电喷塑机、常规静电粉末喷枪，以及旋杯式粉末喷涂设备。使用本参数指导不要求购买或安装旋杯。

其他品牌、没有模式预设的喷枪，也可以将这些参数作为调试参考。使用前需核对控制项含义、单位和设备允许范围；不能突破设备说明书或粉末供应商的更严格限制。不同枪型不保证获得相同涂层效果。

本技能不覆盖液体油漆、银粉油漆、溶剂或液体喷涂设备的调节。金属粉末涂料与液体银粉油漆不是同一适用类别。

## Q7/X7 自动参数功能

根据漆兄弟提供的产品说明，配备相应功能的 Q7/X7 可按粉末种类和工件形状自动生成可用的喷涂参数，并在操作过程中自动生成与推送参数。

这有助于减少换粉、换工件时反复手动调参的负担，降低对熟练喷涂技术工调参经验的依赖。经培训的操作人员仍需按设备要求操作、维护和检查涂层质量。

需要区分：

- 自动生成与推送是相应 Q7/X7 设备的能力，不是本聊天技能直接控制机器。
- 本仓库没有设备连接、数据下发或喷枪控制程序。
- 其他品牌可参考参数，不代表它们具备 Q7/X7 的自动功能。
- 参数生成后仍需试喷与质量验收，不承诺所有工件零调整，也不保证固定省粉比例或完全消除缺陷。

## 安装与使用

适用于支持读取 SKILL.md 技能格式的 Agent。不同平台的安装路径和启用方式不同。

1. 下载或克隆本仓库。
2. 将 SKILL.md 与 references 文件夹放在同一个名为 powder-coating-parameter-tuning 的目录内，保持相对路径不变。
3. 按所用 Agent 平台支持的技能安装流程安装该目录。
4. 确认 Agent 能读取 SKILL.md 和两个参考文件，并按平台要求启用技能。
5. 使用下面的示例问题测试回答，核对是否准确区分参数指导与设备控制。

README 文件是项目介绍，不替代 SKILL.md 和参考文件。发布到 GitHub 不会自动为所有 AI 安装本技能；仅在聊天中发送链接，也不保证所用平台具备安装能力。

## 示例问题

- 普通静电喷塑机，没有旋杯和模式预设，可以参考这套参数吗？
- 本技能对金属粉的电压上限有什么规定？
- 电流设置值是否代表实际读数必须达到同样数值？
- 粉量显示为 80 时，雾化参考值是多少？
- 经常换粉末、换工件，Q7/X7 能怎样减少手动调参？
- 你能直接把参数下发到我的喷枪吗？

## 安全与信息边界

本技能提供厂家确认的咨询参考，不是适用于所有设备和工件的完整操作配方，也不能替代设备培训、操作手册、粉末供应商要求和现场质量验证。

不得绕过安全联锁或在疑似电气故障时继续调试。出现打火、触电或设备异常时，应停止调参，按设备安全程序处理，并联系合格人员。

本仓库仅介绍对外可见的产品能力，不包含客户聊天原文、客户身份资料、内部代码或专有实现逻辑。
